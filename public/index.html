Bảo mật

Doanh nghiệp đăng nhập ngân hàng một lần trên Casso. Ứng dụng chỉ giữ token đọc dữ liệu, thu hồi được bất cứ lúc nào.

Một chuẩn cho mọi ngân hàng

Cùng một định dạng giao dịch cho mọi ngân hàng. Viết tích hợp một lần, dùng cho tất cả.

Tích hợp trong 1 buổi

3 bước như bên dưới. Không cần tự đọc sao kê hay kết nối từng ngân hàng.

Kết nối dữ liệu thật · 3 bước

Thay dữ liệu minh hoạ bằng giao dịch thật của doanh nghiệp bạn

Mỗi bước là đúng lời gọi API mà đội kỹ thuật sẽ viết. Bên phải là request và response thật để CTO đối chiếu.

Gọi API lấy giao dịch

Nhập thông tin API rồi lấy transactions. Gọi identity là tuỳ chọn: xem tổ chức và danh sách tài khoản trên kết nối.

Khoảng thời gian (fromDate / toDate)

Bảng kê hiện ở đây sau khi gọi API thành công ở bước 2.
